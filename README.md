# Dopamine Lock

Dopamine Lockは、SNSを見る前にユーザーが設定した運動ノルマを達成するためのiPhone向けSwiftUIアプリMVPです。

Apple Vision framework（`VNDetectHumanBodyPoseRequest`）でカメラ映像から姿勢を端末内判定し、腕立て伏せ・スクワット・プランクを「回数」で記録します。外部APIやクラウドサービスは使用しません。

## 現在の方針

- 完全無料版として開発中
- 広告なし
- 課金なし
- プレミアム機能なし
- 将来的に広告、サブスクリプション、プレミアム機能を追加しやすいよう、まずはコア体験と設定画面を分離

## コア仕様

- ユーザーは月ごとに、各種目の「1日の目標回数」を設定します。
- 一度設定した目標は、その月の間は変更できません。
- 目標変更は翌月までできません。
- 未達成分は「負債」として翌日に繰り越されます。
- 今日の目標 + 負債を達成するとホームが `UNLOCKED` になります。
- データは端末内の `UserDefaults` に保存します。

## 対応種目と判定方法

| 種目 | 管理単位 | MVPでの判定 |
| --- | --- | --- |
| 腕立て伏せ | 回数 | 体を下げて上げると1回カウント |
| スクワット | 回数 | しゃがんで立ち上がると1回カウント |
| プランク | 回数 | ユーザーが開始と終了を行うと1回カウント |

プランクは秒数管理を行いません。

## 実装済み画面

1. ホーム画面（LOCKED/UNLOCKED、今日の必要量、負債表示）
2. 月間目標設定画面
3. 種目選択画面
4. カメラによる姿勢判定画面
5. 達成画面
6. 設定画面

## 技術構成

- SwiftUI
- iOS 17以上
- Apple Vision framework
- AVFoundation camera capture
- ローカル保存: `UserDefaults`
- 内部Xcodeプロジェクト名: `REPLOCK`（既存互換のため）

## 将来のScreen Time連携予定

MVPではSNSロックの実制御は行わず、以下のApple APIを接続するためのUIと状態管理を先に作っています。

- Screen Time API
- FamilyControls
- ManagedSettings
- DeviceActivity

将来的には、設定画面の「ロック対象SNS」でユーザーが選んだアプリを、`LOCKED` の間だけ制限し、`UNLOCKED` になったら解除する構成を想定しています。

## 初心者向けの実行手順

### 1. 必要なもの

- Mac
- Xcode 15以降
- iOS 17以上のiPhone実機

> カメラとVisionの動作確認は実機を推奨します。シミュレータではカメラ入力が期待通りに動かない場合があります。

### 2. プロジェクトを開く

このフォルダをMacに置き、以下のファイルをダブルクリックします。内部プロジェクト名は既存互換のため `REPLOCK` のままです。

```text
REPLOCK.xcodeproj
```

### 3. 実機iPhoneを選ぶ

1. iPhoneをMacに接続します。
2. Xcode上部の実行先から接続したiPhoneを選びます。
3. 初回のみ、署名設定で自分のApple IDのTeamを選ぶ必要があります。

### 4. 起動する

Xcode左上の再生ボタン（▶）を押します。

ターミナルでビルド確認をする場合は以下を実行します。

```bash
xcodebuild -project REPLOCK.xcodeproj -scheme REPLOCK -destination 'generic/platform=iOS' build
```

### 5. カメラの使い方

1. 初回起動時、カメラ利用の許可ダイアログが表示されたら許可します。
2. ホームから「今月の1日目標を設定」を開きます。
3. 腕立て伏せ、スクワット、プランクの1日の目標回数を決めて固定します。
4. 「カメラで運動を記録」から種目を選びます。
5. 腕立て伏せ・スクワットは、全身が映る距離にiPhoneを置いて動作します。
6. プランクは「開始」を押して姿勢を保ち、「終了」を押すと1回として記録されます。
7. 今日の必要量をすべて達成すると `UNLOCKED` になります。

## カメラ権限について

`Info.plist`相当の設定に、カメラ利用目的の説明文を追加しています。

- カメラは運動回数を端末内で姿勢判定するために使用します。
- 映像や姿勢データは外部APIやクラウドサービスへ送信しません。

## 注意点

- 1日の目標回数は月1回だけ設定できます。
- その月に設定済みの目標は翌月まで変更できません。
- データは端末内の `UserDefaults` に保存されます。
- 設定画面から全データをリセットできます。
- 現時点では実際のSNSアプリ制限は行いません。
